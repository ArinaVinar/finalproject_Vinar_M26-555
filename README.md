# ValutaTrade Hub

**ValutaTrade Hub** — консольное приложение для управления валютным портфелем пользователя. Приложение позволяет регистрировать пользователей, выполнять аутентификацию, управлять валютными кошельками, получать обменные курсы и обновлять их из внешних источников.

## Возможности

- Регистрация пользователей и вход в систему.
- Создание и просмотр валютного портфеля.
- Покупка и продажа валюты.
- Получение обменного курса между двумя валютами.
- Обновление курсов из внешних API.
- Просмотр текущих курсов валют к USD.
- Хранение текущих курсов и истории обновлений в JSON-файлах.
- Логирование действий и ошибок.
- Кэширование курсов с ограниченным временем жизни (TTL).

## Используемые технологии

- Python 3.13+
- uv — управление зависимостями и запуск проекта.
- Requests — HTTP-запросы к внешним API.
- PrettyTable — форматированный вывод таблиц в терминале.
- Ruff — проверка качества кода.
- JSON — хранение пользовательских данных, портфелей, курсов и истории.

## Требования

Перед запуском установите:

- Python версии 3.13 или новее.
- `uv`.

Проверить установку можно командами:

```powershell
python --version
uv --version
```

## Установка

Клонируйте репозиторий:

```powershell
git clone https://github.com/ArinaVinar/finalproject_Vinar_M26-555.git
cd finalproject_Vinar_M26-555
```

Создайте виртуальное окружение и установите зависимости:

```powershell
uv sync
```

## Настройка API

Для получения курсов фиатных валют используется ExchangeRate-API, для криптовалют — CoinGecko.

Для ExchangeRate-API требуется API-ключ. Установите переменную окружения `EXCHANGERATE_API_KEY`.

В PowerShell текущего терминала:

```powershell
$env:EXCHANGERATE_API_KEY = "ваш_api_ключ"
```

После установки переменной запустите приложение в том же терминале.

**Важно:** не добавляйте настоящий API-ключ в Git, README или другие публичные файлы проекта.

## Запуск приложения

Запустите CLI из корневой папки проекта:

```powershell
uv run python main.py
```

После запуска появится приглашение командной строки:

```text
ValutaTrade Hub. Для выхода введите exit.
>
```

Для завершения работы введите:

```text
exit
```

## Команды CLI

Команды вводятся в интерактивном режиме после запуска приложения.

| Команда | Назначение |
|---|---|
| `register` | Регистрация пользователя |
| `login` | Вход в систему |
| `show-portfolio` | Просмотр валютного портфеля |
| `get-rate` | Получение обменного курса |
| `buy` | Покупка валюты |
| `sell` | Продажа валюты |
| `update-rates` | Обновление курсов из доступных источников |
| `show-rates` | Просмотр курсов из кэша |
| `exit` | Выход из приложения |

Доступные аргументы и параметры команд можно уточнить в интерактивном интерфейсе приложения.

### Основные компоненты

- **CLI** — интерактивный интерфейс командной строки.
- **Core** — модели пользователей, кошельков и портфелей, а также бизнес-операции с валютой.
- **Parser Service** — получение курсов от внешних API, обработка результатов и обновление кэша.
- **Infra** — настройки и работа с данными.
- **Logging** — настройка логирования и регистрация действий приложения.

## Хранение данных

Приложение использует JSON-файлы в каталоге `data/`:

- `users.json` — учётные записи пользователей.
- `portfolios.json` — валютные портфели.
- `rates.json` — текущие курсы валют и время последнего обновления.
- `exchange_rates.json` — история полученных курсов.

Каталог `logs/` предназначен для файлов журналов приложения.

Рабочие данные могут изменяться во время выполнения программы. Не размещайте в публичном репозитории реальные пароли, API-ключи или персональные данные пользователей.

Запустить Ruff:

```powershell
uv run ruff check .
```

## Конфигурация

В `pyproject.toml` доступны настройки приложения, включая:

- `RATES_TTL_SECONDS` — время жизни кэша курсов в секундах.
- `BASE_CURRENCY` — базовая валюта.
- `LOG_LEVEL` — уровень логирования.
- `LOG_MAX_BYTES` — максимальный размер файла журнала.
- `LOG_BACKUP_COUNT` — количество резервных файлов журнала.
